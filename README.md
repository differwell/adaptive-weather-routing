# Adaptive Weather Routing for Sailing Vessels

## 🚀 Описание проекта

Данный проект представляет собой **исследовательский прототип системы адаптивной маршрутизации для парусных судов**, учитывающей **неопределённость прогноза погоды**. В отличие от классических навигационных систем, которые строят маршрут один раз и не пересматривают его, наш подход **динамически перестраивает маршрут** на основе прогнозируемой ошибки метеорологического прогноза.

Проект выполнен в рамках научно-исследовательской работы и может служить основой для промышленных систем поддержки принятия решений в судоходстве (особенно в условиях Арктики и Северного морского пути).

---

## 🧠 Основные возможности

- **Загрузка и обработка реальных метеорологических данных**  
  — исторические прогнозы ECMWF (через Open‑Meteo Archive)  
  — реанализ ERA5 (Copernicus Climate Data Store)

- **Физическая модель движения судна**  
  — полярная диаграмма скорости в зависимости от ветра  
  — учёт течений и волнения (упрощённо)

- **Оптимизация маршрута**  
  — дискретная сетка с исключением суши (Natural Earth)  
  — алгоритм A* с эвристикой по прямой

- **Оценка неопределённости**  
  — ансамбль сценариев (генерация множества «что-если»)  
  — статистика времени и риска превышения порога

- **Адаптивный реплан**  
  — ML-модель (XGBoost) для прогноза ошибки ветра  
  — автоматическое решение о перестроении маршрута

- **Визуализация**  
  — интерактивная карта маршрута (Folium)  
  — графики ошибки прогноза, сезонной изменчивости, распределения времени
